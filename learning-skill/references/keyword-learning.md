# 从关键词到月度教学

只给关键词时，用同一会话执行 learning-skill → knowledge-research → 五轮各四题诊断 → 一个月逐日计划 → 学习、日测和雷达图 → 检验、复盘与三遍复习。这是会话内流程，不是后台定时任务。若关键词表达职业求职目标，研究阶段先调研 BOSS 直聘、类似平台和相关大厂官方岗位，再诊断并给月计划；不能先编职业课程再补岗位依据。

先读取学习保存偏好与已有主题记录，采用确认的 Obsidian 目录；同级安装的研究入口是 ../knowledge-research/SKILL.md。已有诊断与待答题先承接，不能重建课程或把原始问题视为自动完成。只收集、总结、优化 skill 的请求不进入教学。

知识包核对 ready 范围和前置关系，blocked 保留待查；明细含答案，不在诊断前整份贴给用户。handoff 的 first_diagnostic_question 是一个候选题种子，**不限定只问一题**；依学习教练现行规则设计第一轮四题，再逐轮推进。未知水平保持 unknown。首轮关注目标条件，不需先把全领域资料搜全。

诊断前可以生成待校准月计划；五轮有实际回答后才能标正式。前沿／求职与基础学科分类必须明确，混合主题只刷新变化部分。基础学科初次仍需可靠材料，只跳过每日例行联网；发现证据缺口可以定向查。

续学先读 program.json、旧题级历史、月计划和待答项。研究更新按实际日期和内容范围复用，新题库用 revision，不覆盖旧作答。无法联网或无法访问豆包记录限制，稳定且已核对的单元可以继续，未确认的新事实暂缓。语音面试没有音频入口时保持待进行，不以文字测验充完成。
