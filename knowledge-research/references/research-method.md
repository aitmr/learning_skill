# 检索与知识提取方法

系统收集一个关键词时读取。以“用证据教一个明确模块”为完成标准。

## 范围与查询

记录原始关键词、展开后的主题、语境、首课行为和排除内容。没有水平信息时只安排资料的难度跨度，不替用户定级。宽主题先画领域地图，首轮聚焦一个可练习行为。

| 方向 | 问题 | 精确化方式 |
|---|---|---|
| 定义与边界 | 是什么，与近似概念有什么区别？ | 全称＋定义／官方概览；缩写展开 |
| 机制 | 输入、过程、输出和条件是什么？ | architecture／how it works，中文同义查询 |
| 前置知识 | 需要先理解或会做什么？ | 从机制中追查未知概念 |
| 实践 | 有什么最小步骤或原始案例？ | 官方 tutorial／worked example |
| 限制与误区 | 哪里失败，哪些条件不能省略？ | limitations／failure，沿引用回溯 |
| 比较 | 不同方案在什么条件下适合？ | 明确比较维度，不只问谁最好 |
| 评估 | 怎样发现做错、检查质量？ | 官方测试指南、原研究指标定义 |

不机械执行全部查询；简单主题可合并方向，不适用时写理由。查询加入具体用途和来源类型，经典理论不强加当前年份。记录真正执行过的检索；失败或空结果也保留。

## 来源的可用范围

先看来源能否回答问题，再看发布者、证据方式、时效和独立性。写具体理由与限制，不用总分制造精确感。

- 官方文档可定义自身接口和行为，不能单独证明优于竞争者。版本和更新时间未注明则留空。
- 原始论文保留任务、数据、实验条件与结论范围。历史贡献与今天的通用实现分开。
- 综述和教材用于领域地图、前置概念与争议脉络；重要结论按需要追溯原始研究。
- 维护者代码和教程用于最小步骤；未执行就标记“文档示例，未运行”。
- 用户文稿保留作者观点与已验证事实的区别，不把局部经验推广到所有人。

查阅日期不是出版日期。重定向后用最终 URL 建索引，保留旧入口；同一网页的参数和锚点不重复算来源。多个网站引用同一研究，记录共同 origin_family。作者、版本、年份和许可未知时不要补造。

## 阅读范围与核对

每份资料记录 read_status 和 covered_locators。读完整相关正文可标为 read；只读论文摘要或部分章节则为 partial。未打开的搜索摘要只作候选，不进入教学事实。

事实保存自己的精简概括与原始定位，保留限定条件。笔记不等于网页快照，无须复制全文。数字、效果、争议和比较声明检查证据是否独立、条件是否相同；直接定义不需硬凑两家转述。部分支持时改写为带条件的 qualified；无法支持时 pending，阻止相关知识点进入首课。

## 教学所需的粒度

每个单元能用一题检查。例如“区分检索与生成”比“掌握所有 RAG”更合适。前置关系代表理解或操作依赖，不是关键词联想。教学例子和误区题标为本次设计；包含新的事实时也补证据。

知识点明细保留解释、依赖、例子、误区、边界、出处、问题和回答要点。知识地图显示顺序，不能替代详细内容。

## 缺口与停止

核心行为、必要前置、一个实践例子、边界和检查方式可追溯时开始教学，进阶资料不必全部读完。一次关键词输入至少要有可教单元，不能只给链接。

检索结果重复时改变措辞、语言、官方入口或引用方向。两轮没有改善则交付可核对部分与下一项查询；接口版本不明时先教稳定概念，暂缓代码指导。宽主题的未覆盖部分进入 gaps，不承诺“全收集”或“百分之百准确”。
