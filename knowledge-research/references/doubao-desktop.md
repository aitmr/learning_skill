用户于 2026-10-23 指定使用截图中的 **豆包 macOS 桌面应用**。这是资料补充的优先入口；与 Microsoft Edge 中未登录的网页版分开。不要因为网页版未登录要求用户重新登录桌面端，也不要替换为火山引擎 API 或为了接入重新下载客户端。

## 连接与发送

- 优先当前可用、已获授权的桌面控制工具。当前环境可用 cua_repl，首次调用按工具的初始化约定选择 `/Applications/Doubao.app`，应用 ID 为 `com.bot.pc.doubao`。若名称或 ID 同时匹配安装目录与挂载安装盘，使用安装目录的完整路径，避免启动另一份。未来路径变化时从应用清单重新发现。
- 读取当前窗口和登录状态。若已有正确的资料补充会话则复用；新主题或联调测试使用单独会话，不改用户无关对话。只发送已准备好的公开主题、目标和资料链接。
- **文字任务使用输入框直接填值。** 2026-10-23 实测剪贴板粘贴曾同时带入截图附件，后改用 setValue 填文本成功。发送前重新读取输入框和附件列表，确认文本正确、没有非预期附件；不自动上传剪贴板图片、学习记录或本地文件。控件编号从新状态读取，不硬编码。
- 一次发出后读取对话，看到用户消息和豆包新结果才能记 sent／returned；不能把“输入框填好了”算已发送。结果正在生成时做本地独立工作，避免连续刷新或重复发任务。
- 按来源核对结果后才写 researched／verified。豆包自称“看过视频”“读过全文”不构成已核验证据；标题、作者、URL、实际章节／字幕及日期逐项对应。拿到视频页面元信息只证明题名等元信息，不证明看过内容。

登录或权限阻碍写入资料日志；优先保留桌面任务，桌面不可用时才检查用户可用的网页会话或交付待运行任务。不得不说明限制时写明实际阻碍，不把未知写成“豆包不支持”。没有本地客户端时不自行安装。
